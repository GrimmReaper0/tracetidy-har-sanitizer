# Changelog

## 1.0.0 - initial prepared release

- Private-by-default, allowlist-based HAR minimization with an explicit diagnostic URL profile.
- Dependency-free ESM engine, TypeScript declarations, and Node CLI.
- Single-file offline browser app with local worker processing, a waterfall, filters, sorting, pagination, and request inspection.
- Cleaned HAR, counts-only JSON audit, and Markdown debugging brief exports.
- Input limits, generic error messages, deterministic builds, CSP hashing, and no-clobber CLI output.
- Synthetic fixtures, canary/immutability invariants, unit/integration/browser tests, and pinned CI/Pages workflows.
- Privacy, architecture, contribution, publishing, and launch documentation.

This heading describes the prepared source release. It does not assert that a GitHub release, npm package, or hosted site has already been published. See docs/VERIFICATION.md for executed checks and unverified scope.
