    What does TraceTidy remove, and what are its limits?

    Both profiles remove all headers, cookie objects, request and response bodies, original timestamps, page labels, URL credentials and fragments, cache details, and unknown fields. Query values are always replaced. Private mode also replaces hosts, path segments, and query names with consistent within-file aliases. Diagnostic mode keeps these strings, so secrets in readable URLs can remain.

    Numerical metadata and request structure remain. Aliases are not cryptographic anonymization, and requests can be correlated within the same file. Malformed fields are normalized, with processing notes in the audit. This tool is not a compliance guarantee, a secret detector, or a full-fidelity HAR editor.

    Does it work without an internet connection?

    Yes. The distribution is one self-contained HTML file with no remote fonts, scripts, analytics, or APIs. Open the file directly in a modern browser. Input is processed by a local Web Worker, not uploaded. Clear the capture or close the tab to release the app's references; this is not a guarantee of secure memory erasure.
